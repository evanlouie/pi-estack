# AGENTS.md

## Project Description

pi-estack is the personal Pi package for
[evanlouie](https://github.com/evanlouie/) containing an assortment of Pi
extensions/skills/prompts/themes.

## Skills

When creating, updating, or touching any skills, read through all of the agent
skills documentation: <https://agentskills.io/llms.txt>

Scripts in skills must be self-contained and written in either Python using uv
or TypeScript using Deno.
